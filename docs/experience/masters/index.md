# Masters

I am studying MSc AI in Bioscience at Queen Mary University of London, building on my biochemistry background through programming, bioinformatics and biological data analysis. My studies combine practical computing exercises with biological questions and collaborative project work.

## Skills developed

- **Programming and problem-solving:** Used Python and Jupyter to process data, create visualisations and troubleshoot code.
- **Bioinformatics:** Applied Linux workflows to sequencing quality control, genome assembly and variant analysis.
- **Reproducible analysis:** Used Git, Conda environments and documented workflows to organise work and track changes.
- **Collaboration:** Contributed to a group COVID-19 dashboard project, combining data analysis, visualisation and communication.
