# Unix and Analysis of Large Genomic Datasets

Analysed short- and long-read sequencing data from fire ants and Plasmodium falciparum, developing practical skills in Linux, bioinformatics and genomic data interpretation.
Skills developed

- Linux and Bash: Worked on remote Linux systems and used shell commands, scripts and loops to organise data and process multiple samples.
- Sequencing quality control and assembly: Assessed and cleaned Illumina reads with FastQC and Trimmomatic, assembled sequences with SPAdes, and evaluated assembly quality with QUAST.
- Gene annotation: Predicted genes using MAKER and Augustus, and assessed protein predictions using BLASTP and UniProtKB/Swiss-Prot.
- Variant analysis: Aligned reads with Bowtie2 and minimap2, processed alignment files with SAMtools, and identified SNPs and structural variants using BCFtools and Sniffles.
- R and population genetics: Used R Markdown, adegenet and PopGenome to visualise genetic variation, explore population structure and compare genetic diversity.
- Biological databases: Queried NCBI, UCSC, COSMIC and cBioPortal to investigate gene annotations, transcript isoforms and cancer mutation patterns.
- Reproducible analysis and troubleshooting: Managed Conda environments, documented commands and software versions, and resolved software dependency issues.

The module strengthened my ability to work with unfamiliar software, assess data quality and connect computational results with biological questions.
