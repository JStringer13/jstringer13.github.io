# Coding for Bioscientists

## Introduction and overview

Developed practical Python skills for biological data analysis, progressing from core programming concepts to sequence analysis, AI-assisted coding and interactive data visualisation.

The module combined Jupyter notebook exercises with bioinformatics applications and a group hackathon, applying programming skills to biological sequences and public-health data.

## Skills developed

- **Programming:** Python, reusable code, object-oriented design, debugging and testing.
- **Data analysis:** API access, JSON, pandas, data preparation and interactive visualisation.
- **Bioinformatics and AI:** Biological sequence processing and critical evaluation of AI-generated code.
- **Version control:** Managed project history, reviewed changes and resolved conflicts using Git and GitHub.
- **Teamwork and communication:** Collaborative problem-solving, developing a shared application and explaining technical work.

## Practical work

### 1. First steps in Python

- Wrote and ran Python code using variables, data types, arithmetic and user input.
- Manipulated strings, including simple DNA and RNA sequence examples.

### 2. Collections

- Used lists, tuples and dictionaries to organise biological data, with indexing, slicing and comprehensions.

### 3. Conditional statements

- Applied Boolean logic and `if`/`elif`/`else` statements to make decisions and filter data.

### 4. Iterative constructs

- Used `for` and `while` loops, `zip`, `break` and `continue` to automate repetitive calculations and sequence processing.

### 5. Working with files

- Read, parsed and wrote FASTA and CSV files, using context managers to handle files reliably.

### 6. Functions

- Wrote reusable functions with arguments, return values and docstrings, applying them to biological sequence processing.

### 7. Modules

- Organised code into reusable modules, worked with imports and namespaces, and included standalone test code.

### 8. Object-oriented programming and error handling

- Created classes with attributes and methods, and explored inheritance and polymorphism.
- Used exception handling and custom exceptions to manage invalid input and runtime errors.

### 9. Biopython

- Used sequence objects for reverse complementation, transcription and translation.
- Read FASTA and GenBank records with SeqIO and explored BLAST search results with SearchIO.

### 10. Git and GitHub

- Managed an example RNA-seq metadata project with Git, using commits to inspect changes and maintain a clear project history.
- Used branches and GitHub pull requests, resolved merge conflicts and configured `.gitignore` to exclude generated outputs.

### 11. AI-assisted programming

- Used Ollama and GitHub Copilot CLI to explain, generate and debug small bioinformatics scripts.
- Wrote focused prompts, reviewed proposed changes and tested translation, reverse-complement and GC-content code against independently checked examples.

### 12. COVID-19 dashboard — group project

- Collaborated on an interactive COVID-19 dashboard during a 24-hour hackathon, retrieving UKHSA data through an API and organising JSON responses into pandas DataFrames.
